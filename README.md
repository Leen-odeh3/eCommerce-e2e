# E-commerce Test Suite with Cypress

This repository contains a **Cypress-based end-to-end (E2E) testing framework** for validating key user flows on [automationexercise.com](https://automationexercise.com).

## Overview
Automated testing is a crucial part of modern web development to ensure software quality and reliability. This project focuses on testing an e-commerce website by simulating real user interactions such as:

- User registration and authentication  
- Adding and removing products from the shopping cart  
- Completing the checkout process  
- Verifying user permissions and page navigation  

By covering these scenarios, the test suite helps catch regressions early and guarantees that key functionalities work as expected.

## Key Features

- **Well-structured test code** organized with Cypress best practices using `describe` and `it` blocks for clarity and maintainability.  
- **Dynamic test data generation** with [faker.js](https://github.com/faker-js/faker) to simulate realistic user inputs, reducing flakiness and improving test coverage.  
- **Detailed reports and screenshots** captured for each test run to aid in debugging and tracking test results over time.  
- **Reusable page objects and custom commands** to make the test suite scalable and easy to extend.
